# Wine Quality — часть 4

Локальное приложение Streamlit для оценки вина готовым пайплайном StandardScaler + LogisticRegression. Модель не обучается. Хорошее вино означает исходную оценку не ниже 7.

## Запуск

Нужен Python 3.14:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Возможности

Четыре вкладки: оценка одного вина, модельные метрики, пакетное предсказание, коэффициенты. Общий порог в сайдбаре влияет на все решения; начальное значение из `config.json`. Класс 1 получается при вероятности не меньше порога, класс 0 — при меньшей вероятности.

## Кэширование

`st.cache_resource` сохраняет общий объект модели на сервере. `st.cache_data` сохраняет таблицу и рассчитанные вероятности, возвращая копии данных. Изменение порога меняет сравнение и метрики, а не вероятности тестовой выборки. Без декоратора `joblib.load` заново читает модель при каждом перезапуске скрипта. После замены артефактов перезапустите сервер, чтобы сбросить кэш.
