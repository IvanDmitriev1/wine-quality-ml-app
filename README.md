# Wine Quality — часть 4

Локальное приложение Streamlit для оценки вина готовым пайплайном StandardScaler + LogisticRegression. Модель не обучается. Хорошее вино означает исходную оценку не ниже 7.

## Запуск

Нужен Python 3.14. Откройте терминал в папке `wine_app`:

```bash
python -m pip install --upgrade -r requirements.txt
python -m streamlit run app.py
```

После обновления зависимостей полностью перезапустите процесс Streamlit.

Версии в `requirements.txt` — последние стабильные релизы PyPI на 7 ноября 2026 года. Проверено на Python 3.14.10: `pip check`, запуск четырёх вкладок и смена порога на 0 и 1.

Модель сохранена с scikit-learn 1.6.1, поэтому при загрузке в 1.9.1 появляется `InconsistentVersionWarning`. Все 1950 вероятностей и решений проверены относительно результатов до обновления (допуск вероятностей `1e-12`). Межверсионная загрузка официально не гарантируется: https://scikit-learn.org/stable/model_persistence.html. Модель не переобучалась и не перезаписывалась; для поддерживаемого переноса нужен повторный экспорт из обучающего окружения с новой версией scikit-learn.

## Возможности

Четыре вкладки: оценка одного вина, модельные метрики, пакетное предсказание, коэффициенты. Общий порог в сайдбаре влияет на все решения; начальное значение из `config.json`. Класс 1 получается при вероятности не меньше порога, класс 0 — при меньшей вероятности.

## Кэширование

`st.cache_resource` сохраняет общий объект модели на сервере. `st.cache_data` сохраняет таблицу и рассчитанные вероятности, возвращая копии данных. Изменение порога меняет сравнение и метрики, а не вероятности тестовой выборки. Без декоратора `joblib.load` заново читает модель при каждом перезапуске скрипта. После замены артефактов перезапустите сервер, чтобы сбросить кэш.
